# Acid VOG installation
Download Acid-VOG-Windows-x64 from a successful GitHub build's Artifacts section. Extract the download and any ZIP inside it.

Copy the complete Acid VOG.vst3 folder into:
C:\Program Files\Common Files\VST3

Restart the DAW and rescan VST3 instruments. Add Acid VOG to a MIDI/instrument track. Choose a scene and press START, or choose MIDI keyboard mode and play incoming MIDI notes.

Standalone: launch Acid VOG.exe and select your audio output device in its audio settings. Choose your MIDI input there if you use MIDI keyboard mode.

Uninstall: close the DAW and remove the installed Acid VOG.vst3 folder. Saved .vacid patches are independent files.
